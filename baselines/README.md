# 운영진 베이스라인 보관

`organizer_v7/`는 운영진이 제공한 Uni-D 베이스라인 v7의 코드 원본을 비교용으로 보관한 폴더입니다. 사용자 지정 `open/uni_d_baseline_v7/`에서 아래 다섯 파일만 수정 없이 복사했습니다.

- `model.py`
- `train.py`
- `test.py`
- `README.md`
- `requirements.txt`

노트북, 데이터, 가중치, 예측, 로그, 다운로드 링크를 넣은 `setup.sh`는 포함하지 않습니다. 원본 확인과 비교를 위해 이 스냅샷에는 자동 포맷이나 팀 모델 수정을 적용하지 않습니다.

현재 팀 모델과 제출 진입점은 저장소 루트의 `model.py`, `train.py`, `test.py`입니다. 이 베이스라인은 로지스틱 회귀와 과거 방향 시계열 특징을 사용하는 별도 구현이며, 루트의 CNN·MLP 모델과 가중치 형식이 다릅니다. 자세한 차이와 규정 검토는 `docs/rules_review.md`를 참고하세요.

원본 베이스라인을 실행하려면 사용자가 GPU 서버의 개인 작업 폴더에서 직접 진행합니다. 의존성은 이 폴더의 `requirements.txt`를 기준으로 확인하고, 공용 패키지 변경은 팀원과 조율하세요. 실행 산출물은 Git에서 제외되는 별도 실험 폴더에 보관합니다. 최종 제출에는 선택한 모델의 코드·가중치·재현 결과를 명확히 지정해야 합니다.
